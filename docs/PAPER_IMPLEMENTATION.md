# 论文公式与实现对应

本轮只修改 ASP-PHBSC。论文正文、PBESO 和 ETSC 均未修改。缺失的实验扰动模型和完整观测器增益按作者要求保留待填。

## 模型与离散化

每轴物理状态为 x = [位置误差, 速度误差]，测量为相对位置减期望相对位置。基础模型为双积分器。给定待填的扰动模型后，构造：

~~~text
A = [[A0, B0*Cw], [0, Aw]], B = [B0; 0], C = [C0, 0]
z = [x_hat_delayed; w_hat_delayed]
Ad = exp(A*T)
Bd = integral(exp(A*s)*B, s=0..T)
Ld = integral(exp(A*s)*L, s=0..T)
~~~

代码通过分块矩阵指数计算这些量。B_d 不再置零，连续增益 L 也不再直接充当离散残差增益。所有矩阵、增益和状态维度都需要一致。

论文实验只给了两分量 L，而增广观测器至少需要三分量；不能据此猜测扰动状态的增益。公共配置保留论文给出的两分量数值作为已知记录，另有三个必须补齐的字段：

| 字段 | 需要提供的内容 |
| --- | --- |
| disturbance_dynamics | A_w，l_w × l_w 矩阵 |
| disturbance_output | C_w，长度为 l_w 的行向量 |
| augmented_observer_gain | 完整连续 L，长度为 2 + l_w |

这些字段为空时，控制节点在创建控制发布器前报错退出。单元测试中的人工模型仅用于验证公式，不是实验配置。

## 零基时间索引

第 i 步开始时，z_i 对应物理时刻 i-n_tau 的延迟估计。实际输入历史按从旧到新保存 u_(i-n_tau), ..., u_(i-1)，负索引历史初始化为零。

~~~text
xw_hat_i = Ad^n_tau*z_i
           + sum(Ad^(n_tau-1-r)*Bd*u_(i-n_tau+r), r=0..n_tau-1)
y_pred_i = C*Ad*z_i + C*Bd*u_(i-n_tau)
y_bar_i = measured_delayed_y_i  if a real new sample is available
          y_pred_i             otherwise
z_(i+1) = Ad*z_i + Bd*u_(i-n_tau) - Ld*(y_bar_i - C*z_i)
u_i = -K*x_hat_i - Cw*w_hat_i
~~~

当前状态预测使用 z_i，不把更新后的 z_(i+1) 错当作 z_i；因此当前测量的校正作用从下一步开始体现。这是按照论文印刷的离散式执行的明确约定。论文输出预测式的下标与“一步预测”含义存在歧义，本次没有擅自改论文或替换成另一组公式。

未来预测使用当前可用测量、复制的观测器状态和已知/预测输入。未来尚未到达的慢采样数据不当作已知，预测末端状态也不会覆盖当前观测器状态。

## 控制包与事件触发

- N_p = 100 对应 101 个三轴输入，覆盖 0 到 100。
- 控制端和执行端分别保存自己的包。新实测到达时重建控制端包；其他步骤只移位，末项补零。第 0 步按论文的成功初始传输假设初始化。
- 先把旧执行端包移到当前时刻，再用当前首输入计算事件误差，避免把旧时刻输入用于比较，也避免用接收后的相等缓冲区把误差清零。
- 事件误差是三轴首输入差的欧式范数；阈值使用六维物理状态估计的范数，不含扰动状态。
- 超时从上一次发送尝试计起；失败发送也更新时间，成功接收时间另行保存。
- DoS 只阻止新触发包的交付。执行端每一步继续取当前包的首输入；移位尾部补零，不再保持最后一个值。

统一三轴发包是本实现明确采用的组织方式；论文没有说明历史实验是否采用逐轴独立触发。软件通道与缓冲逻辑在一个进程内，不能据此宣称已经在独立硬件链路部署。

## 无人机接口

视觉测量为 r_qt = p_t - p_q，误差为 e_r = r_qt - r_qt_star。论文虚拟输入是误差系统的 u = -a_q，所以无人机加速度命令需要在接口处反号。原有硬件限幅保留在接口，限幅后的命令再转回虚拟输入进入下一步历史。

单个快速时钟驱动三轴。有效测量按照可核对的 ROS 同步时间戳排队，以 n_tau*T 为目标龄期；重复、过期或丢失目标的消息不当作新有效采样。首个有效样本定义慢采样相位；后续有效样本释放间隔必须是 M=5 个快速步的正整数倍。若出现 4、6 等步间隔，控制运行会明确终止，不重新标记时间戳或静默改变采样时刻。10、15 等步间隔可以表示丢失中间样本，诊断会记录实际间隔；这些丢样情况不构成论文稳定性结论已被验证的证据。ROS 调度和实际相机采样仍有至多一个快速周期的释放容差及处理误差，需要实测验证。

默认启动不再把动捕转发给 MAVROS 外部视觉或飞控里程计。动捕数据只进入真值记录，控制器需要独立的 FCU/VIO 定位来源。相机外参、AprilTag 尺寸和推力标定未重新辨识。
